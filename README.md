# Bokutobi Remix
## *"I Was Publicly Accused and Exposed, So I Jumped from the Rooftop"*

> An open remix universe based on the original work.
## English

This repository is an open space for **derivative works, remixes, and reinterpretations** of:

"I Was Publicly Accused and Exposed, So I Jumped from the Rooftop"

The canonical version is available at:
- bokutobi-canon

---

## ■ Rules (Simple)

### ■ Core Character Constraints

The following three characters are core elements of the work.
Their fundamental roles must not be altered:

- Ruika Shibuki: made a false confession  
- José Amaha: learned the truth and jumped from the rooftop  
- Mutsuki Kagiroi: deeply loves José  

※ These core events and relationships must remain intact

---

### ■ What You Can Do

You are free to:

- Modify personality and psychological portrayal  
- Change specific actions and events  
- Create alternative developments (including "what if" scenarios)  
- Expand the world  
- Add new characters  

---

## ■ Naming Convention (Recommended)

SURNAME Given

Examples:
- SHIBUKI Ruika  
- AMAHA José  
- KAGIROI Mutsuki  

※ Not mandatory

---

## ■ Accent Note

The official romanization of Joze Amaha is "José".  
If accented characters are not supported, "Jose" may be used.
